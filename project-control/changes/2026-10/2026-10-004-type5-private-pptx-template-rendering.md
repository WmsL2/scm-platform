# Change Record：类型 5 私有 PPTX 真模板渲染

日期：2026-10-09

## 变更

- 四套业务模板改为基于私有 `*_CLEAN.pptx` 的标准商品页/封面生成，保留页尺寸、主题、母版、布局、背景和源页静态图形关系。
- CLEAN 资产由原始受控样例一次性净化：动态文本框改用语义槽位名，商品图片替换为透明占位媒体，未选页面、备注和外链关系移除。运行时只按槽位名处理 CLEAN 页，并始终从未填充的页复制。
- 新增严格的模板槽位清单，动态替换标题、正文、价格和商品图片；套装在源图片区内排版，长字段沿用同一源页生成“详情续页”。
- 输出会移除未选源页、源商品图片槽位、动态旧文案和文本链接；资产缺失显式失败，不会回退到代码重绘。
- 开发/测试默认读取 Git 忽略的 `.codex-assets/ppt-template-sources/`；生产必须配置 `PPT_TEMPLATE_ASSET_DIR` 到授权私有存储。
