# 类型 1/2 限价统一使用协议价

日期：2026-10-14  
状态：COMPLETED

## 变更

- 类型 1/2 报价资格由成本价改为协议价有效且不超过客户限价。
- 限价保持为当前上传需求的可选字段；没有限价列或行内限价值为空时不执行价格上限过滤，不设置任何默认限价。
- 类型 2 候选排序改为最低协议价优先。
- 类型 1/2 自动 Selection、价格快照及报价回填价格改为协议价。
- 人工选择接口对类型 1/2 同样强制校验并冻结商品协议价，避免绕过自动匹配规则。
- 增加成本价更低但协议价超限仍被排除、最低协议价正确选中，以及无客户限价时不执行上限过滤的回归测试。

## 影响

- API / UI / Permission：无路径、界面或权限变化；仅修正类型 1/2 的价格业务语义。
