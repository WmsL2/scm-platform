# 2026-09-28 商品编辑百分比精度修复

## 问题

商品详情把数据库比例转换为页面百分比时使用 JavaScript `Number` 乘除。数据库值 `0.1970` 在编辑回传时可能变成 `0.19699999999999998`，即使运营只修改采销员，也会因为完整编辑请求携带该值而触发后端 `DECIMAL(9,4)` 校验错误。

## 修改

- 商品比例字段改为十进制字符串移位，不经过二进制浮点运算。
- 数据库存储值 `0.1970` 在页面精确显示、编辑为 `19.70`，提交时精确恢复为 `0.1970`。
- 京东价毛利、扣点复核、毛利率、好评率、折扣率和价格虚高比例统一使用该规则。
- 超过百分比两位小数的输入按数据库比例四位精度进行四舍五入。

## 数据库与接口

- Alembic Revision：无。
- API 字段和权限：无变化。
- 数据库既有 `DECIMAL(9,4)` 精度不变。
