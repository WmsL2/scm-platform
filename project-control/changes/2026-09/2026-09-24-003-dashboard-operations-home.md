# 2026-09-24 工作台运营首页

## 目标

项目进入本地部署使用阶段后，移除工作台中的 Sprint、建设进度、开发边界和技术模式信息，将首页调整为运营人员可直接使用的业务入口。

## 实现

- Dashboard 汇总接口增加正常合作供应商、进行中项目、待归档供应商和最近 5 个项目。
- 工作台“待处理事项”卡片暂不查询数据，固定显示 `--` 并注明待办流程跑通后接入。
- 最近项目按更新时间倒序排列；仅向具有 `bid:list` 权限的用户返回，避免首页泄露项目明细。自由推品项目进入 Agent 工作台，其他项目进入项目详情。
- 首页快捷入口按当前账号权限显示，不展示用户无权访问的业务入口。
- 商品与供应商 Excel 导入快捷入口进入对应主数据页后直接打开文件选择器，复用既有预览和确认流程。
- Dashboard API 仅提供已有明确处理入口的待归档供应商计数。
- 侧边栏只在“供应商管理”显示待归档角标；“工作台”“商品主数据”“投标项目”均不显示待办角标。样式与注册审批一致，计数为 0 时隐藏，最大显示 `99+`。
- 工作台页面与全局布局复用 Dashboard Pinia Store，并对并发刷新去重；登录和路由切换时刷新，退出登录时清空。
- 新建项目快捷入口使用 `action=create` 打开既有创建弹窗，不新增重复页面。
- 删除原前端硬编码的建设进度、Sprint、Local-First 与 FastAPI 状态文案。

## API / UI / Permission

- API：扩展 `GET /api/v1/dashboard/summary` 响应字段。
- UI：工作台改为业务统计、最近项目和快捷入口。
- Permission：无新增权限；快捷入口复用现有前端权限，后端业务接口继续执行原有权限校验。
- Alembic Revision：无。
