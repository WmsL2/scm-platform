# 2026-09-28 京东价毛利展示回归保护

## 问题

数据库比例值 `0.2290` 在旧页面经 JavaScript `Number(value) * 100`
转换后会得到 `22.900000000000002`，而非运营应看到的 `22.90`。

## 变更

- 为商品详情百分比转换新增截图对应的双向回归断言：
  `0.2290 → 22.90`、`22.90 → 0.2290`。
- 继续使用既有十进制字符串移位实现，不通过 JavaScript 二进制浮点数完成比例换算。

## 影响

- Alembic Revision：无。
- API、权限、数据库 Schema：无变化。
- 需重新构建并部署 Web Admin 前端产物，浏览器强制刷新后生效。
