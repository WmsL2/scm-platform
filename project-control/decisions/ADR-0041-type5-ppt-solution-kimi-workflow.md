# ADR-0041：类型 5 PPT 方案使用 Kimi 与人工选品闭环

状态：ACCEPTED
日期：2026-09-28

## 决策

- 类型 5 项目以甲方文字需求为输入，项目可选上传 `.pptx` 模板；未上传时使用系统默认商务版式。
- Kimi 只负责需求理解、从受控商品候选中排序推荐，以及在人工确认后生成原生可编辑 PPTX；不得直连或写入正式业务库。
- 后端始终从有效 Product Master 和有效 Supplier Master 检索真实商品，Kimi 返回的商品 ID 必须属于后端提供的候选集合。
- 推荐结果必须经过人工确认。人工可将两个及以上已确认商品组成套装，数量与价格快照由系统计算，套装总价不得超过所选价格档位。
- 生成输入只包含人工确认的单品、人工套装和冻结快照；已进入套装的商品不再作为单品重复展示。
- 客户模板优先；无客户模板时通过固定生成指令使用默认商务版式。生成结果作为 `PPT_EXPORT` 版本文件保存并允许下载、提交。
- Kimi 对话模型与 Hosted PPT Agent 均通过环境变量配置。未配置时项目仍可创建，但运行推荐或生成会进入明确的失败状态，不得伪造成功文件。

## 后果

- 新增 `scm_ppt_solution_package`、`scm_ppt_solution_package_item`、`scm_ppt_generation_task`，Revision `20260928_0041`。
- 复用类型 4 的 Run、候选、人工确认和项目状态机，但类型 4 的 V4 全量硬筛逻辑不变；类型 5 使用独立 Kimi 语义选品 Runner。
- Hosted Agent 真实生成仍依赖企业侧 Kimi 账号、Agent ID 与 Environment ID，部署前必须用真实凭据完成联调。
