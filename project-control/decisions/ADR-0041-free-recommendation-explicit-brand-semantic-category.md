# ADR-0041：自由推品明确品牌与语义类目硬筛选

状态：ACCEPTED  
日期：2026-09-28

## 决策

- 在 ADR-0040 的数值硬条件基础上，Type-4 Requirement V5 仅对客户明确强制指定的品牌和类目增加硬筛选。
- 明确品牌由 `required_brands` 表示，商品 `brand` 使用大小写无关的包含匹配；多个可接受品牌按任一品牌匹配。
- 明确类目保留客户原词，并由 Agent 输出 `category_intents` 的同义/近义类目词。正式商品查询在一级、二级、三级类目名称中按任一词匹配，解决需求语言与商品类目名称不一致的问题。
- 普通品牌偏好、场景、用途、主题、节日、数量、库存、物流、资质和价格有效期保持忽略，不作为筛选或排序条件。
- 仅 V5 新 Run 采用该规则，历史 V3/V4 Run 不回写也不改变其既有候选结果。

## 后果

- 每次新 Run 仍只调用一次 DeepSeek 进行结构化需求解析；不会为每件商品调用模型或生成推荐理由。
- 语义类目词由 Agent 提供并经 Pydantic 结构化校验，商品查询、供应商状态过滤、候选快照和人工确认仍由后端确定性处理。
- 无新增表、无 Alembic Migration、无新增权限。
