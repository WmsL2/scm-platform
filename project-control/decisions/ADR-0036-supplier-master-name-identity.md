# ADR-0036：Supplier Master 名称主体判重

状态：ACCEPTED
日期：2026-09-22

## 背景

同一公司名称在 Excel 和数据库中可能仅有中英文括号、空格或标点差异。旧预览按原字符串比较，可能显示通过，而确认时数据库比较返回“该供应商已存在”。

## 决策

- Supplier Master 新增、改名、Excel 预览和确认共用 `supplier_name_identity_key`：先做 Unicode NFKC 和大小写折叠，再按顺序仅保留 Unicode 字母与数字。
- 保留所有主体文字和数字，包括地区与公司后缀；不使用相似度、拼音、简称、AI 或语义判断。纯标点或空白名称无有效键，拒绝入库。
- 比较键仅用于判重；正式 `supplier_name`、Excel 原值及现有 `supplier_id` 不自动改写、合并或删除。
- 活跃记录同键视为已存在；仅一条已逻辑删除记录同键时沿用既有恢复规则；多条已删除记录同键时拒绝自动选择。
- Excel 内同键重复标记后续行；确认重新判重，若预览后名称已被占用，整批回滚。
- 商品导入的来源供应商匹配仍遵循 ADR-0008 严格 NFKC/空白规则，不引入去标点匹配，避免错误绑定。

## 边界

第一版不加数据库标准化键唯一索引、无 Alembic 迁移。现有原名 UNIQUE 仍保留，但不同标点变体在极端并发创建时存在应用层竞争窗口；上线前应盘点历史主体同名记录，后续如需强并发保证，另立数据清洗及数据库唯一键迁移。不得自动合并已有 Supplier 及其商品关系。
