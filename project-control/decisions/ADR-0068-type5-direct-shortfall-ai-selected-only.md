# ADR-0068：类型 5 单品价格档短缺时仅保留 AI 匹配结果

状态：ACCEPTED  
日期：2026-10-16

## Context

ADR-0067 让类型 5 单品价格档数量不足的 Run 保持可人工确认，但其实现跳过 AI 匹配并展示了完整冻结候选池。冻结池含所有已通过通用商品资格的商品，并不等于各价格档的匹配结果；因此价格档外商品也会出现在候选表中。

用户需要在短缺时看到已经匹配到的商品，而不是完整召回池。

## Decision

- 本 ADR 取代 ADR-0067 中“短缺时保留全部冻结候选且不调用 AI 排序”的决定。
- 类型 5 `SINGLE` 的每个价格档只要存在合格候选，仍执行既有 AI 评分与最终选择。
- 当一个价格档的可用数小于 `item_count` 时，本次 AI 选择数量为 `min(可用数, item_count)`；只持久化 AI 选出的商品，随后删除未选中的冻结候选。
- Run 进入 `WAITING_CONFIRMATION` 并保留短缺警告，警告须说明各档可用数、目标数和实际 AI 匹配总数。
- 若所有价格档均没有可匹配商品，保持既有失败路径；提供方、合同和其他运行失败也保持失败，不能以短缺为由展示完整冻结池。

## Consequences

- 短缺 Run 仍可人工确认和生成 PPT，但表内只含价格档内且已由 AI 匹配出的商品。
- 无新表、Alembic Revision、API 路径、权限或新增配置项。
