# ADR-0043：自由推品模板列号映射

状态：ACCEPTED  
日期：2026-09-28

## Context

旧版自由推品模板映射使用 `商品字段 key -> 模板表头文字` JSON。它要求表头文字在工作表中唯一，也要求同一个商品字段只映射一次；因此客户模板中的重复“采购”等表头无法确认，也不能把一个商品字段写入多个目标列。

## Decision

- 新确认的映射使用 V2 列号合同：`{"version": 2, "columns": [{"column_index": 8, "field_key": "purchasing_agent"}]}`。
- `column_index` 是上传工作表中一开始计数的物理列号；每个目标列只允许配置一次，同一个 `field_key` 可出现多次。
- 导出按 V2 物理列号写入，允许重复表头和重复来源字段；模板列不存在、为空或索引重复时拒绝确认或导出。
- 既有 `字段 key -> 唯一表头` 映射保持只读、可导出兼容；它遇到重复表头仍按旧规则拒绝，运营重新确认后会保存为 V2。

## Reason

列号是同一上传工作簿内唯一且可直接写入的目标标识，避免以显示文本作为字段标识而产生覆盖和歧义，同时不需要修改已生成的历史导出快照。

## Consequences

- 前端显示每列列号；重复表头不再禁用，同一商品字段不再被其他行占用。
- 无新增表、无 Alembic Migration、无新增权限；复用既有 `mapping_json` JSON 列和模板 SHA 校验。
- 自动映射按每一列生成 V2 项，重复表头会各自获得同一默认字段，人工仍可调整。
