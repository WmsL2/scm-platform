# ADR-0015：商品停用与永久删除

状态：ACCEPTED
日期：2026-09-11

## Context

商品大表是正式商品主数据来源。原“逻辑删除后重新导入即恢复旧商品”的规则会保留旧的上架日期、价格和规格，容易使 Excel 新数据未被察觉地忽略。

## Decision

- Product 生命周期采用 `ACTIVE` / `DISABLED`；停用不是删除，保留商品、审计字段和 `source_supplier_id + sku` 唯一键。
- 停用商品不参与正常商品列表、详情、编辑、成本价更新和报价选品。重新启用只能走受权限保护的显式命令，并重新校验来源供应商可用性。
- 固定商品大表导入遇到同键停用商品必须报错，不能恢复、不能新建重复记录、不能以 Excel 静默覆盖旧字段；同键正常商品继续阻止导入。
- 仅已停用商品可永久删除。永久删除须 `product:purge` 权限、前端 SKU/名称二次确认与 API `confirm: true`；服务端事务锁定商品、写入最小删除审计、执行物理删除，并由外键约束拒绝已有受保护关联的记录。
- 永久删除后唯一键释放；再次导入同键 Excel 行创建一条新 Product，使用当前批准的 32 列映射。
- `product:disable` 负责停用/启用，`product:purge` 负责永久删除；旧 `product:delete` 权限和 `is_deleted` / `deleted_by` / `deleted_at` Product 字段废止。原有 `product:delete` 的角色授权迁移为 `product:disable`，永久删除默认仅授予系统管理员。

## Reason

停用满足正式商品暂不使用但仍需保留的场景；永久删除满足导入错误或测试数据明确不保留历史、且需要用新 Excel 重新建档的场景。两种操作和导入防重结果明确可见，避免旧字段残留。

## Consequences

- Revision `20260911_0020` 将现有逻辑删除商品迁移为 `DISABLED`，并新增停用审计、永久删除审计和权限数据。
- ADR-0013、ADR-0014 被本 ADR 替代；不再提供 Import Confirm 隐式恢复已删除商品。
- 未确认导入任务和本地图片清理不属于永久删除范围，仍按既有本地媒体生命周期 Handoff 处理。
