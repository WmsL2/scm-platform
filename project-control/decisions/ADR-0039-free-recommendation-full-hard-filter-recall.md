# ADR-0039：自由推品 V4 全量硬条件召回

状态：ACCEPTED  
日期：2026-09-28

## 决策

- 类型 4 新 Run 只将商品主数据可验证的数值条件作为筛选条件：协议价、明确京东价、折扣率和点位（`gross_margin`）。
- 场景、用途、主题、节日、类目、品牌、履约物流、库存、资质、数量和价格有效期一律不参与筛选；不再由 AI 选择 1–5 个类目。
- “可满足 9 折”按 `discount_rate_max=0.9` 解析，不再误解为必须等于 0.9。
- 系统持久化全部符合条件的 Product/Supplier 冻结快照，不再限制 30 条、不再调用模型做商品排序或生成逐条理由。展示评分使用商品主数据的 `positive_rating`。
- 候选 API 使用服务端分页。批量确认同时支持当前页面显式候选与“当前 Run 所有未确认候选减去排除项”的服务端范围选择，避免客户端传输全部 ID。
- 历史 Run 保持只读兼容；新规则不回写历史候选、理由、分数或确认记录。

## 后果

- 新 Run 的候选集可能显著增大，用户必须通过分页和人工确认管理结果。
- 无新增表或 Migration；复用现有 Run 解析 JSON、候选快照和确认表。
