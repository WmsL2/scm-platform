# ADR-0054：类型 5 相关三级类目覆盖选品

状态：ACCEPTED
日期：2026-10-09

## 背景

类型 5 已对完整冻结池进行场景与性价比评分，但全局高分短名单可能集中在同一三级类目。对于客户未限定单一类目的奖品、日用品或场景方案，最终结果因此可能缺少相关品类覆盖。

## 决策

- 仅调整类型 5 的直接选品链路；类型 1–4 的召回、排序、接口与页面不变。
- 首轮仍对每件冻结候选完成场景、价值和综合评分，不增加商品理由字段或额外模型输出。
- 进入最终 AI 精选前，服务端将已评分候选按三级类目轮换：每个类目的最高分商品优先进入短名单，随后再加入同类目的后续高分商品。
- 最终提示词要求：客户未明确限定单一类目时，优先覆盖多个场景相关的三级类目；相关性与价值接近时优先未覆盖类目；不得为了凑类目选择无关商品；明确单类目或相关候选不足时允许同类目多选。
- 最终精选因输入预算无法调用模型时，沿用同一类目轮换顺序作为已评分候选的安全兜底。

## 后果

- 最终请求仍只返回短编号，不返回逐件理由；不会增加理由类输出 Token 或新增 API 字段。
- 短名单大小和全量评分请求数量不变；仅改变短名单内候选的排列与最终提示词。
- 前端继续显示既有三级类目列，人工可勾选确认最终结果。
