# ADR-0057：类型 2 受控品牌归一化

状态：ACCEPTED  
日期：2026-10-12

## 背景

类型 2 必须判断客户需求与正式商品是否为同一商品。型号中的空格、斜杠和连字符已有确定性归一化，但品牌原值可能同时包含中文名、英文名或业务修饰词，例如“联想”“Lenovo”“联想Lenovo”和“中国联想电脑”。直接比较原始字符串会漏匹配，简单的字符串包含或相似度匹配又可能把“联想惠普通用配件”等歧义输入错误归到单一品牌。

## 决策

- 每次匹配任务仅使用符合商品及来源供应商资格的正式商品品牌构建一次受控品牌目录，并在全部需求行间复用。
- 中英文连续片段可成为同一商品品牌的别名；“电脑”“集团”“公司”“品牌”等已冻结后缀可被安全移除，剩余文本只允许唯一命中目录品牌。“中国”等也可能属于正式品牌名称的前缀不直接删除，但“中国联想电脑”仍可通过唯一目录品牌“联想”完成归一化。客户原值和商品主数据均不修改。
- 品牌输入必须唯一定位到一个目录品牌组，之后才允许与归一化后完全相等的型号共同构成同品条件。
- 同时命中多个品牌组时保持 `NO_MATCH`；不得以最低价、商品名称相似度或任意一个命中品牌消除歧义。
- 型号不使用编辑距离或包含匹配。只忽略大小写、全半角、空格和受控分隔符，避免把 `TN328` 与 `TN328C` 判为同品。
- SKU/采购方编码精确命中仍具有最高优先级；同品候选仍按正数且不超过限价的当前成本价选择最低价。
- 当前不在匹配请求中调用 AI。未知品牌保持未匹配；未来 AI 只能针对未识别品牌给出受 Pydantic Schema 约束的目录品牌建议，不能直接选择商品或写正式业务库。

## 后果

- “联想”“Lenovo”“中国联想电脑”可与目录中的“联想Lenovo”稳定匹配，统一业务含义为“联想”。
- 原始品牌、正式商品品牌、选品快照和导出值继续保留，不发生主数据覆盖。
- 匹配审计规则版本升级为 `v2`，别名命中以 `CANONICAL_ALIAS` 信号记录，并保存目录推导出的中文优先标准品牌名（如“联想”）；原商品品牌展示值不被覆盖。
- 不新增数据库字段、Migration、API 或权限。
