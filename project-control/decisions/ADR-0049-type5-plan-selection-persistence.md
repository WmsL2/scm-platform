# ADR-0049：类型 5 方案选择持久化

状态：ACCEPTED
日期：2026-10-08

## 背景

类型 5 原“确认本方案商品”只创建商品确认记录，不记录用户点击的是哪张方案卡。不同方案可以包含重叠商品，因此不能根据已确认商品可靠反推已选方案；刷新页面或重新进入项目后也无法持续高亮。

## 决策

- 在 `scm_ppt_solution_plan` 增加 `is_selected`、`selected_by`、`selected_at`，将方案选择作为独立、可审计的业务状态保存。
- 新增方案选择 API。一次请求在同一事务中复用既有商品资格复核与确认规则，并标记对应方案已选。
- 方案列表回传选择状态，Web 工作台以绿色卡片和“已选方案”标签显示持久化结果。
- 当前允许同一 Run 累计选择多张方案，与既有多次确认商品的累加语义一致；本次不引入自动取消其他方案或自动撤销商品确认。
- 方案选择沿用 `recommendation:review` 权限，已完成选品的项目仍须先返回待选品状态才能继续选择。

## 后果

- Revision `20261008_0047` 为历史方案补充默认未选择状态，不改动已有商品确认记录。
- 方案选择、商品确认、选择人和选择时间可在刷新及后续流程中稳定读取。
- API 响应增加方案选择字段；类型 4 流程不受影响。
