# 2026-09-30 类型 5 DeepSeek + Python PPT 交接

## 当前可用闭环

1. 类型 5 创建项目，填写需求并可选上传客户 `.pptx`。
2. DeepSeek 仅在后端受控商品候选中做需求理解与排序。
3. 人工确认商品，可组合价格档位套装，完成选品。
4. Python 在本地创建原生可编辑 PPTX，保存为版本化 `PPT_EXPORT` 并可下载。

## 部署配置

- 只需要现有 `DEEPSEEK_*` 配置；不再设置 `KIMI_*`。
- 后端安装项目依赖，`python-pptx` 会随 `pip install -e .` 安装。
- 本机 `TASK_MODE=inline` 可执行；正式环境可继续接入既有 TaskQueue abstraction。

## 已知范围

- 默认模板按固定单品页生成：顶部商品名称、左侧参数、中央分隔线、右侧商品图；每个单品或套装一页，所有文字均可编辑。
- 本地商品图片会自动插入；套装最多展示四张。没有图片时显示明确提示。
- 上传客户模板时首版保留其页面并追加生成页；不猜测客户模板字段，不自动替换模板占位符。
- 商品图片真实插入与按客户模板精确排版需要拿一份目标客户模板及商品图片数据再继续实现。

## 建议验收

1. 使用一份已人工确认单品及套装的类型 5 项目，分别测试“系统默认模板”和“客户模板”生成与下载。
2. 在 PowerPoint/WPS 中编辑标题、表格单元格并保存，确认文件不是页面图片。
3. 用实际客户模板确认其保留页面与追加页面是否满足业务展示要求；确认后再决定是否引入模板字段填充规则。
